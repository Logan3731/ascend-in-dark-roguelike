# 14. 레퍼런스(Darkness Survival) 반영 설계 결정 + 작업 프롬프트

작성: 2026-11-06 · 근거: 노션 「레퍼런스 분석 정리 — Darkness Survival (플레이 흐름 기준)」와 내 게임 코드 비교, 그리고 질문 답변.
원칙: **기본 시스템은 레퍼런스를 그대로 따른다.** 레퍼런스의 이름·그림·수치는 가져오지 않고 시스템 아이디어만 쓴다.
작업 규칙: 커밋·푸시는 사용자가 시킬 때만 한다 (메모리 규칙). 레퍼런스 원본(`*.apk`, `darkness_assets/`)은 저장소에 올리지 않는다.

## A. 결정 사항 (확정)

### A1. 층 진행 분기
- "서두름"을 따로 판정하지 않는다. 층이 오를수록 적이 강해지고, 파밍을 충분히 했는지는 **플레이어 스펙**이 가른다.
- 해금한 아이템·룬이 얼마나 되는지에 따라 갈 수 있는 층이 사실상 한정된다. 파밍을 다 하고 올라가도 스펙이 모자라면 죽을 수 있다.
- 난이도 상승: **적 레벨·능력치**, **함정 증가**. (엘리트는 아래 A5)

### A2. 전투 기본기
| 항목 | 결정 |
|---|---|
| 회피·막기 | 플레이어와 적 모두 **회피 15%, 막기 15%**. 회피는 피해 0, 막기는 피해 80~100% 감소. |
| 다트 | 기본 **5개** 지급. 던져서 피해. **함정이나 적에게 던지면 사라지고, 빈 바닥에 던지면 그 자리에 남는다**(주울 수 있음). 함정에 던져 작동시킬 수 있다. |
| 스킬 | 기존 **Q 강타는 빼고**, **3연격**(연속 3회 공격)과 **점프 찍기**(범위 공격 + 기절)를 넣는다. |
| 쿨타임 표시 | 버튼 아래 **점**으로 표시, **점 1개 = 2턴**. 기력(기존 MP)을 소모하고 기력은 턴이 지나면 자연 회복. |
| 보조무기 | 한손 무기를 보조칸에 장착하면 **보조무기가 20% 확률로 추가 타격**. 보조무기는 주무기로 쓸 때보다 **공격력이 낮다**. |
| 방패 | 보조칸에 장착. 딜은 약하지만 **때렸을 때 기절 확률**이 있다. 딜은 보조무기가 방패보다 세다. |
| 걷는 속도 | 한 칸 **0.55초** (지금 0.4초는 너무 빠르다고 함). |

### A3. 상호작용 규칙·이동
- 걷는 중 클릭하면 **목표를 자유롭게 바꿀 수 있다** (현재 방식 유지).
- **상호작용 중, 적 발견 중 등 무언가 진행되는 동안에는 입력을 막는다**(예약도 불가). 적 발견 시 `!`와 함께 진행 중이던 것이 일시정지.
- **클릭을 계속 누르고 있으면 계속 간다.**

### A4. 함정·돋보기
- 함정은 **가시 / 독 / 경보** 세 종류.
  - 경보 함정: 주변 적이 깨어나고, 적이 **소리가 난 곳으로 모여든다**.
- 기본적으로 **함정은 타일을 밟으면 보인다**.
- 기본 상태에서도 **낮은 확률로 발견**할 수 있다.
- **돋보기 버튼**: 누르고 움직이면 한 칸 움직이는 데 **2턴**이 들지만, 주변의 숨겨진 기믹·함정을 발견할 확률이 크게 오른다.

### A5. 엘리트 층 (5층, 10층)
- 엘리트는 **5층, 10층**에만 나온다 (매번 나오지 않음). 현재 코드의 `RunState.BossFloors = {5, 10}`과 같다.
- 엘리트 층은 **각자 테마 맵**이다. 기본 던전 테마는 유지하고, 구간마다 테마가 바뀌는 게 아니다.
- 엘리트 층은 **미로가 없고, 다른 방보다 넓다.** 엘리트 방에는 **엘리트 하나만** 있다.
- 엘리트를 **처치하면 하나뿐인 문의 잠금이 풀리고**, 그 방에 **계단이 있다.**
- 엘리트를 잡고 올라가면 **원래 나오던 몬스터 수를 줄이고 새 몬스터를 넣는다.** 기존 몬스터 이름만 바꾸는 게 아니라 새 종류를 만든다.
- **5층 테마: 묘지·지하 납골당.** 엘리트: **거인 해골**.
  - 느리지만 한 방이 아프고, **타격마다 파편이 튀는 단순한 탱커**.
  - 평소엔 **기본 공격을 하다가 일정 확률로 패턴**이 나온다.
  - 패턴 ① **전방 3칸 휘두르기** ② **포효: 몬스터 주위 8칸 피해 + 밀려나기**.
  - 패턴은 **한 턴 전에 바닥에 붉은 칸으로 예고**한다 (침 뱉는 슬라임의 주황 칸 예고 방식을 재활용).
- **6층 신규 적: 해골 병사** (기존 몬스터 수를 줄이고 투입).
- 10층 테마·엘리트는 **아직 미정**.

### A6. 맵 환경 (이번에 넣을 것 전부)
- **팁 표지판**: 방 진입 팝업(`RoomHint`)을 표지판 오브젝트로 바꾼다. 계단 방에는 반드시 1개, 클릭하면 돈이 나올 확률이 있다. 이미 나온 팁도 가끔 다시 나온다. 팁 표지판이 없는 아이템은 상단에 설명을 표시한다.
- **물 타일**: 불에 타는 중 들어가면 불이 꺼진다 (불꽃 물약·횃불과 연결).
- **풀**: 다가가면 일정 확률로 돈·아이템. 불로 태울 수 있고, 태우면 돈은 남고 아이템은 사라진다. 이슬이 나오면 체력 회복.
- **바닥 타일 종류**를 여러 가지로, **보너스방**(돈·아이템이 가득)을 1층에서 체험시킨다.

### A7. 상점과 준보스
- 상점은 **준보스 층**에 둔다 (레퍼런스: 상인은 준보스가 나오는 층과 같다).
- 준보스 층은 **3층과 8층**. 넓은 방 한가운데에 준보스 한 마리가 있고, 그 방에 보상이 많다. **계단을 막지 않는 선택 전투**다.
- 상인 위치: 1층(튜토리얼, 그대로), **3층, 8층**. 기존 4층·9층 상인은 3층·8층으로 옮긴다. (`RunState.MerchantFloors`: {1, 4, 9} → {1, 3, 8})
- 준보스: 3층 거대 슬라임(체력 60), 8층 해골 대장(체력 100). 자세한 내용은 15번 문서.

## B. 아직 정하지 않은 것

1. **해금 요소** (회차가 쌓일수록 열리는 세계): 지금 `TowerMemory`는 수치 강화 5종뿐. 직업·룬·시작 장비·아이템 풀 해금을 어떻게 할지 질문하지 않았다. A1에서 "해금한 룬·아이템이 갈 수 있는 층을 정한다"고 했으므로 **가장 큰 미결 항목**.
2. **10층 테마와 엘리트**.
3. 점프 찍기·3연격의 정확한 기력 소모량과 쿨타임 점 개수, 3연격·점프 찍기의 피해 배율.
4. 방패·보조무기를 어디서 얻는지 (상자, 상인, 제작).
5. 돋보기 버튼의 발견 확률 수치, 함정 피해량·개수 곡선.
6. 시작 화면 메타 허브(직업·룬·기억의 상자)와 광고·캐시 요소 (이번 범위에서 제외).

### 프롬프트 2 — 이동·상호작용 규칙

```
[작업: 이동·상호작용 규칙]
설계 문서 A3을 구현해라. (전투 기본기 덩어리가 끝난 뒤에 한다)

- 걷는 중 다른 곳을 클릭하면 목표만 바뀌는 지금 방식은 유지한다.
- 상호작용(상자·항아리·석관·우물·문·상인·대화)이 진행되는 동안, 그리고 적을 발견해 `!`가 뜬 연출 동안에는 모든 입력(이동 클릭, 스킬, 던지기, 먹기 단축키)을 막고 예약도 받지 않는다. 기존 TurnResolver.BusyUntil/DialogUI.IsOpen 등으로 이미 막히는 것과 안 막히는 것을 먼저 조사해서 표로 보여준 뒤 구멍만 메운다.
- 적 발견 시(Monster의 `!` 팝업 지점) 연출이 끝날 때까지 BusyUntil을 늘리는 방식으로 일시정지시킨다. 이미 걷던 길은 GridClickMover.StopWalking으로 끊는다.
- 마우스를 계속 누르고 있으면 계속 걷는다. 지금 HandleHold는 0.25초 지연 후 커서 칸이 바뀔 때만 목표를 갱신하는데, 커서가 한 칸에 머물러도 목표에 도착한 뒤 커서 방향으로 계속 이어 가는지 확인하고, 안 되면 고친다.
- 마지막에 확인한 시나리오와 못 한 것을 보고해라.
```

### 프롬프트 3 — 함정·돋보기

```
[작업: 함정과 돋보기]
설계 문서 A4를 구현해라. (1번 전투 기본기가 끝난 뒤. 다트를 함정에 던지는 훅을 쓴다)

- 새 스크립트 Trap.cs: 종류 세 가지.
  - 가시: 밟으면 피해.
  - 독: 밟으면 PlayerStats.Poison(turns)로 중독.
  - 경보: 밟으면 근처 잠든 적을 깨우고(Monster의 소리 깨우기 WakeFromNoise/MakeNoise를 재활용), 깨어난 적이 함정 위치로 모여들게 한다.
- 함정은 평소에 숨겨져 있고 밟으면 보인다. 밟지 않고도 낮은 확률로 발견된다(플레이어 주변 일정 반경, 매 턴 확률 굴림. 확률·반경은 상수).
- 돋보기 모드 버튼(HUD 버튼 + 단축키): 켠 상태로 움직이면 한 칸 이동에 2턴(TurnResolver.BeginTurn/ResolveAttacks를 두 번)이 들고, 발견 확률이 크게 오른다. 숨겨진 기믹(비밀 방의 무너진 벽 Rubble 등)도 발견 대상으로 한다.
- 다트·돌멩이를 함정 칸에 던지면 함정이 작동하고 다트는 사라진다(Thrower의 훅 사용).
- 몬스터도 함정을 밟는지는 이번에 하지 않는다.
- FloorGenerator에서 층 번호에 따라 함정 수가 늘도록 한다(1층 튜토리얼은 함정을 적게 또는 안내용 1개만).
- 마지막에 고른 수치와 확인 못 한 것을 보고해라.
```

### 프롬프트 4 — 맵 환경·팁 표지판

```
[작업: 맵 환경과 팁 표지판]
설계 문서 A6을 구현해라. (2번 이후)

1) 팁 표지판: FloorGenerator.AddHint가 만드는 RoomHint(방에 들어서면 자동 팝업)를 표지판 오브젝트(TipSign.cs, Interactable)로 바꾼다. 클릭하면 팁 한 줄이 로그/대화로 뜨고 일정 확률로 골드가 나온다. 계단이 있는 방에는 반드시 1개를 놓는다. 본 팁은 TowerMemory.MarkHint로 기록해 다음 회차에서 줄어들게 하되 가끔 다시 나온다. 팁이 없는 아이템은 상단에 설명을 표시하는 기능이 이미 있는지 확인하고 없으면 만든다.
2) 물 타일: WaterTile. 불에 타는 중(횃불을 든 채가 아니라, 불꽃 물약·불붙은 상태가 있는지 코드로 확인하고 없으면 만들지 말고 먼저 보고) 들어가면 꺼지는 상호작용. 처음엔 일부 방에만, 발견의 재미를 위해 설명 없이.
3) 풀: Grass. 다가가면 확률로 골드·아이템, 불(ThrownTorch, 불꽃 물약)로 태울 수 있고 태우면 골드는 남고 아이템은 사라진다. 이슬이 나오면 체력 회복.
4) 바닥 타일 종류를 2~3가지로 섞고, 돈·아이템이 가득한 보너스방을 1층에서 1개 체험하게 한다 (비밀 방 시스템 재활용 가능).
5) 불 물약/횃불 불꽃이 풀과 물에 닿는 규칙을 한 곳(예: 새 Fire 유틸)에 모은다.
- 마지막에 확인 못 한 것과 고른 수치를 보고해라.
```

### 프롬프트 5 — 5층 엘리트 층

```
[작업: 5층 엘리트 층 (묘지·납골당, 거인 해골)]
설계 문서 A5를 구현해라. (1번 이후. Boss.cs와 RunState.BossFloors가 이미 있으니 먼저 읽는다)

- 엘리트 층(RunState.BossFloors의 5, 10)은 미로 없이 넓은 방 하나로 만든다. FloorGenerator에 엘리트 층 전용 생성 경로를 추가한다. 입구와 문 하나, 그 방(또는 문 너머의 작은 방)에 계단. 엘리트를 쓰러뜨리면 그 문의 잠금이 풀린다. StairsEvent가 지금 Boss가 살아 있으면 계단을 막는데, 새 규칙(잠긴 문 + 계단)과 어떻게 합칠지 정리해서 적용한다.
- 5층 테마: 묘지·지하 납골당. 기존 관·뼈 소품(Coffin, BonesEvent)을 재활용하고, 엘리트 방에는 엘리트만 둔다.
- 거인 해골(신규 몬스터): 느리지만 한 방이 아프다. 맞을 때마다 파편이 튄다(연출, 가능하면 주변 칸에 짧게 피해 표시). 평소엔 기본 공격, 일정 확률로 패턴.
  - 패턴 1: 전방 3칸 휘두르기.
  - 패턴 2: 포효 — 자기 주변 8칸에 피해 + 플레이어 밀려나기(벽에 막히면 밀려나지 않고 추가 피해 없음).
  - 둘 다 한 턴 전에 바닥에 붉은 칸을 표시해 예고한다. 침 뱉는 슬라임(Behavior.Spitter, PlanSpitter)의 주황 칸 예고 로직을 재활용한다.
  - Monster의 Behavior에 새 값을 추가하는 방식으로 구현하되 기존 몬스터 동작은 바꾸지 않는다.
- 해골 병사(신규 일반 몬스터): 6층부터. 방패로 막기 확률이 높은 중간 체력 적. 5층 엘리트를 잡고 올라간 뒤(RunState로 구분) 기존 몬스터(슬라임·늑대·박쥐·쥐) 수를 줄이고 해골 병사를 섞는다.
- 모델이 없으면 기존 몬스터 프리팹/기본 도형으로 임시 처리하고, 필요한 에셋(거인 해골, 해골 병사 모델)을 목록으로 보고한다 (VARCO/Blender로 따로 만들 예정).
- 마지막에 고른 수치, 임시 처리한 것, 확인 못 한 것을 보고해라.
```
