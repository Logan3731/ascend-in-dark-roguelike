# 레퍼런스 분석 — Darkness Survival (2026-11-02)

원본 게임의 에셋 폴더(이미지·효과음·텍스트 데이터)를 **참고용으로만** 살펴본 기록. 원본 파일은 프로젝트에 넣지 않는다.

## 2. 재미의 핵심이라고 본 것

1. **방에 들어갈 때마다 "뭐가 있지?"** — 소품 밀도. 우물에 물건을 던져 보고, 책장에서 물약 정보를 얻고, 관을 열고, 솥에서 물약을 만든다. 탐험 = 작은 선택의 연속.
2. **잠든 적과 기습** — 조용히 다가갈지(기습 보너스), 피해 갈지, 깨워서 싸울지. 우리 게임의 "횃불 = 시야 ↔ 들킴"과 잘 맞는다.
3. **피로와 모닥불** — 긴장(탐험) ↔ 휴식(모닥불) 리듬. 요리·회복의 안전 지대.
4. **함정과 숨겨진 것** — 걷는 것 자체에 긴장과 보상이 생긴다.
5. **소리** — 모든 행동에 소리가 붙어 있어 손맛이 산다.

## 3. 우리 게임에 가져올 것 (제안 순서)

1. **잠든 적 + 기습** (횃불을 들면 더 잘 보이지만 적이 잘 깬다 → 빛 테마와 연결) — ✅ 반영 (2026-11-02)
2. **방 소품 늘리기**: 책장(물약 정체 힌트), 관(뼈·유품·가끔 언데드), 우물(물건 던지기 → 랜덤 보답), 무너진 벽(곡괭이로 숨은 통로)
3. **모닥불 휴식**: 맵 곳곳의 모닥불 자리, 나뭇가지로 불 붙이고 쉬기(체력·기력 회복, 그동안 배고픔 소모)
4. **함정**: 바닥 함정 몇 종(가시·독·알람), 횃불 빛 안에서는 보인다
5. **효과음**: 무료 라이선스 효과음(예: freesound CC0)으로 행동마다 소리
6. **카메라 줌아웃**: 방 하나가 한 화면에 들어오게
