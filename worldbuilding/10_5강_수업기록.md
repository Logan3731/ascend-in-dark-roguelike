# 5강 수업 기록 — 미니 레벨 제작 · VARCO 3D 에셋 배치 · 걸음 애니메이션

> 초안은 AI가 작업 기록을 바탕으로 정리했다. 제출·게시 전 본인 말투로 다듬을 것.

## 1. 핵심 개념
- **프리팹(Prefab)**: 미리 만들어 두고 찍어 쓰는 오브젝트 틀. 원본 하나를 고치면 맵에 깔린 모든 복사본이 함께 바뀐다.
- **칸(그리드) 이동**: 바닥을 칸으로 나누고 클릭한 칸까지 최단 경로(BFS)로 한 칸씩 이동. **한 칸 = 한 턴.**
- **시야 가림 처리(Occlusion)**: 카메라와 플레이어 사이를 가리는 벽만 반투명하게 바꾼다.
- **FBX 축 변환**: 3D 프로그램마다 위쪽 축이 달라(Z-up / Y-up) 가져올 때 회전값이 붙는다. 이 값을 덮어쓰면 모델이 눕는다.
- **리깅·스키닝·애니메이션**: 뼈대를 넣고(리깅), 정점이 어느 뼈를 따라 움직일지 정하고(가중치), 뼈를 키프레임으로 움직인다.
- **애니메이터 상태 전환**: 움직이는 중 = Walk, 멈춤 = Idle. 스크립트가 `Moving` 값을 바꿔 전환한다.

## 2. 사용한 도구
| 도구 | 용도 |
|---|---|
| Unity + Unity MCP | 미니 레벨 생성, 프리팹·스크립트·머티리얼 설정, 씬 캡처 |
| VARCO (MCP) | 3D 에셋 6종(이미지 → 3D 변환), 돌바닥·돌벽 텍스처 |
| Blender + Blender MCP | 주인공 뼈대·가중치·걷기/서 있기 애니메이션, FBX 내보내기 |
| Claude Code | 위 도구를 MCP로 연결해 작업 지시·문제 해결 |

## 3. 결과물
- 씬 `Tower_MiniLevel`: 1층 입구 방 + 2층 미로(방 4개), 15×17칸, 한 칸 크기 4
- 시스템: 클릭 칸 이동 + 흰 테두리 목적지 표시, 턴 카운트, 벽 투명 처리, 가까운 쿼터뷰 카메라, 횃불 조명
- VARCO 3D 에셋: 주인공, 거대한 문, 아이템 상자, 곡괭이·도끼, 굶주린 고블린, 돌계단
- VARCO 텍스처: 돌바닥, 돌벽 (반복 타일)
- 주인공 걷기·서 있기 애니메이션, 손에 붙은 횃불

## 4. 진행 과정
1. 큐브와 프리팹(바닥·벽·문·계단·상자·도구·고블린·주인공)으로 미니 레벨 제작
2. 플레이 감각 조정: 높은 벽 + 가리는 벽 투명화 → 바닥 칸 구분 → 클릭 이동(한 칸 한 턴) → 레퍼런스(Darkness Survival)처럼 가까운 카메라·넓은 방 → 칸 크기 2 → 3 → 4
3. VARCO로 에셋 생성 → Unity로 가져와 프리팹 안의 큐브를 모델로 교체 → 크기·방향·위치·재질 조정
4. 걸음 애니메이션: VARCO 리깅이 막혀 Blender로 전환
5. 벽·바닥에 VARCO 돌 텍스처 적용

## 5. 성공 / 실패 / 수정 과정
**프리팹 교체의 효과**
- 벽 프리팹 하나의 높이만 바꾸자 맵 전체 벽이 바뀌었고, 머티리얼 세 개만 바꿔 바닥 100여 칸과 벽 전체에 돌 텍스처가 들어갔다.

**벽 너머 바닥이 클릭되지 않음**
- 원인: 마우스 광선이 불투명한 벽에 먼저 맞았다.
- 수정: 벽을 무시하고 바닥 높이 평면과 만나는 지점으로 칸을 계산.

**상자가 옆으로 누움**
- 원인: VARCO FBX에는 축 변환용 회전(X 270°)이 들어 있는데, 방향을 돌리면서 그 값을 덮어썼다.
- 수정: 원래 회전값 위에 Y축 회전만 곱하도록 바꿈 → 이후 에셋(문·도구·고블린·계단·주인공)은 처음부터 똑바로 섰다.
- 그 밖에: 모델 중심이 가운데라 절반이 바닥에 묻힘 → 바닥 위로 올림 / 반사가 강해 하얗게 보임 → 매끄러움 낮춤 / 얇은 문틀이 벽에 파묻힘 → 방 쪽 벽면에 붙여 세움.

**VARCO 리깅이 막힘 → Blender로 전환**
- 노드를 만들 때마다 서버 오류가 나서 리깅·애니메이션 노드를 쓸 수 없었다.
- Blender에서 직접 뼈대 19개를 몸에 맞춰 넣었다. 자동 가중치는 AI 메시의 조각 때문에 실패해, 정점마다 가장 가까운 뼈에 붙이는 방식으로 직접 계산했다(손이 허벅지에 붙지 않도록 영역 분리).

**걸음이 도착 후에도 이어지고, 가만히 있을 때 갑자기 걸음**
- 원인: FBX로 내보낼 때 걷기·서 있기 트랙이 둘 다 켜져 있어 서 있기 동작 안에 걷기가 섞여 들어갔다.
- 수정: 트랙을 끄고 다시 내보낸 뒤, 서 있기 동작에 다리 움직임이 없는지 데이터로 확인. 마지막 칸 도착 직전에 멈춤 신호를 미리 보내도록 스크립트도 수정.

**횃불이 팔을 따라오지 않음**
- 원인: 횃불이 손이 아니라 캐릭터 기준점에 붙어 있었다.
- 수정: 횃불 막대·불꽃·불빛을 오른손 뼈의 자식으로 옮김.

## 6. 포트폴리오용 작업 설명 (3~5줄)
턴제 로그라이크 RPG의 미니 레벨을 Unity에서 큐브와 프리팹으로 만들고, 클릭 칸 이동(한 칸 = 한 턴)·목적지 표시·시야를 가리는 벽 투명화를 구현했다.
VARCO로 주인공·거대한 문·상자·도구·고블린·계단 3D 에셋과 돌 텍스처를 생성해 프리팹을 교체하며 크기·방향·재질을 맞췄다.
VARCO 리깅이 막히자 Blender에서 직접 뼈대와 가중치를 만들고 걷기·서 있기 애니메이션을 제작해 이동과 연동했다.
FBX 축 회전, 애니메이션 트랙 혼입 같은 문제를 원인부터 찾아 해결했다.
