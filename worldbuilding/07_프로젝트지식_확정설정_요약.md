# 확정 설정 요약 — 가제 미정 (턴제 로그라이크 RPG)

> Claude Project의 **프로젝트 지식**에 올리는 문서. 인터뷰 결과 중 현재 유효한 설정만 정리했다.
> 표기: **[확정]** 기획자가 결정 · **[AI 제안 채택]** AI가 제안하고 기획자가 받아들임 · **[미결정]** 아직 정하지 않음
> 상세 이력은 `02_확정_설정.md`의 수정 기록 참고.

## 0. 기본
- [확정] 장르: 턴제 로그라이크 RPG · 생존 제작
- [확정] 테마: "모든 걸 잃어도, 경험은 남는다."
- [확정] 레퍼런스 게임: Darkness Survival
- [미결정] 게임 제목 (GDD 제출 가제 "기억의 탑"은 기억 요소 삭제로 재검토)
- [확정] 대화 원칙: 탑 안의 존재는 기본적으로 말하지 않는다. 필요한 장면에는 기획자가 대사를 넣을 수 있다.

## 1. 역사 — 세계의 진실 (엔딩 전까지 숨김)
- [확정] 선의 신과 악의 신은 오랫동안 인간 세상을 두고 다퉈 세상을 망가뜨렸다. 직접 싸우는 대신 "인간을 더 강하게 움직이는 본성이 세상을 가진다"는 내기로 결판을 내기로 했다. [AI 제안 채택]
- [확정] 두 신에게는 각자의 후계자(자식)가 있었으나 둘 다 이미 죽었다.
- [확정] 내기: 각 신은 **상대 신의 죽은 후계자**를 골라 "나의 본성이 더 강한 영향력을 가진다"에 건다.
  - 선의 신 → 악의 신의 아들(남자 주인공)이 선을 택하게 만들겠다.
  - 악의 신 → 선의 신의 딸(여자 주인공)이 악으로 무너지게 만들겠다.
- [확정] 신들은 죽은 후계자의 **복제인간**을 만들어 탑에 올린다. 복제가 죽으면 시체는 그 자리에 **뼈만** 남고, 1층에서 새 복제가 깨어난다. 탑에서 발견되는 뼈와 유품 = 이전 복제들.
- [확정] "올라가야 한다.."는 깨어날 때 두 신이 주입한 말이다. 복제는 본성 외에는 아무것도 기억하지 못한다(이름 포함).
- [확정] 판정: 꼭대기에 도착한 복제의 선/악 수치로 결정. [AI 제안 채택]
  - 남자 + 악 높음 = 악의 신 승 / 남자 + 선 높음 = 선의 신 승
  - 여자 + 선 높음 = 선의 신 승 / 여자 + 악 높음 = 악의 신 승
- [확정] 최종보스는 항상 **나를 고른 신**(남자 = 선의 신, 여자 = 악의 신). 부모 신과는 싸우지 않는다. [AI 제안 채택]
  - 본성을 지킨 경우: 진 신이 결과를 받아들이지 못하고 덤빈다.
  - 본성을 바꾼 경우: 이긴 신이 "이제 너는 내 것"이라며 데려가려 하고, 주인공은 "이건 내 선택이었다"며 맞선다.
  - 부모 신은 엔딩 연출에만 등장할 수 있다.

## 2. 지리 — 탑
- [확정] 외부와 단절된 거대한 탑. 창문이 없고 바깥이 보이지 않는다. 1층에서 위로 오른다.
- [확정] 모든 층은 돌로 지어진 어두운 미로. 맵을 밝히며 위로 가는 계단을 찾는다.
- [확정] 1층: 거대한 문과 그 옆의 곡괭이·도끼뿐(미로 아님). 문 안으로 들어가면 계단.
- [확정] 일반 층: 나무·돌이 있을 수도 없을 수도 있음. 아이템 상자, 몬스터.
- [확정] 테마 층: 가끔 등장 — 울창한 숲, 고대 유적, 늪지대 등.
- [확정] 판타지 세계라 빛 없이도 나무가 자란다(설명하지 않음).
- [미결정] 초반 고블린이 등장하는 층

## 3. 정치 — 세력과 관계
- [확정] 종족: 엘프(인간과 비슷), 슬라임, 동물, 벌레, 곤충, 암석거인, 고블린 등.
- [확정] 조력자 = 고블린 / 중립 = 초식동물 / 적대자 = 그 외 전부.
- [확정] 고블린 분기: 초반에 굶주린 고블린을 만난다.
  - 식량을 나눠주면(식량 −1) 조력자가 되어 이후 층에서 가끔 아이템을 준다.
  - 처치하면(골드 +25) 고블린 종족이 적대자가 된다.
- [확정] 두 신의 대립이 세계 전체의 권력 구조다.

## 4. 종교/신화
- [확정] 선의 신과 악의 신이 존재한다. 주인공들은 각 신의 자식(반신)이지만 본인은 인간인 줄 안다.
- [미결정] 탑의 종족들이 신이나 꼭대기에 대해 품은 믿음

## 5. 경제 — 생존과 자원
- [확정] 허기를 계속 채워야 한다. 식량은 동물 사냥·상자 파밍·자판기(골드)로 얻는다.
- [확정] 골드는 자판기 같은 장치에서 물약·식량 구매에 쓴다(말하는 상인 없음).
- [확정] 나무·광석은 도끼·곡괭이로 채집, 일부 재료는 맨손 채집 가능.
- [확정] 장비는 직접 제작. 도구 = 무기. 도구·무기·횃불 모두 내구도가 있고 다 쓰면 파괴.
- [확정] 첫 횃불: 미로 입구에서 어둠을 먼저 겪은 뒤 근처 상자에서 얻는다. 이후 횃불은 나뭇가지 + 천으로 제작.
- [미결정] 자판기를 누가 설치했는지

## 6. 마법/기술 — 성장 규칙
- [확정] HP/MP. 모든 스킬(마법·물리)은 탐험 중 줍는 두루마리로 배우고 MP를 소모. MP는 물약으로 회복.
- [확정] 장비 슬롯: 모자 / 상의 / 하의 / 상하의(일체형) / 신발
- [확정] 경험치로 레벨업. 죽으면 레벨·장비·스킬·아이템 모두 초기화.
- [확정] **경험의 정수**: 복제가 죽으면 탑이 그 전투 경험을 흡수해 정수로 쌓고, 다음 복제가 정수로 스탯·효율을 영구 강화한다. 정수로 강화하지 않으면 끝까지 오를 수 없다.
- [확정] 선/악 스탯: 이벤트 선택으로 변동. 일정 수치 이상이어야 열리는 선택지가 있고, 높아지면 칭호를 얻는다.
- [미결정] 시작 선/악 수치, 증감량, 칭호 이름·기준·효과 / 검을 제작 무기로 넣을지

## 주인공
| 항목 | 남자 (첫 플레이) | 여자 (남자 클리어 후 해금, 하드모드) |
|---|---|---|
| 정체 | 악의 신의 죽은 후계자의 복제(반신) | 선의 신의 죽은 후계자의 복제(반신) |
| 이름 | 플레이어 입력("이름이 뭐였지..?") | 같음 |
| 능력 | 힘이 세다(데미지 강함), 시작 옷 하나 | 민첩(데미지 약함), 시작 장비가 더 많음 |
| 시작 차림 | 누더기 튜닉 + 밧줄 허리띠 | 일체형 누더기 가죽 옷(팔토시 포함 세트) + 부츠 |
| 성격 | 강점 대담 / 약점 호의적이지 않음 | 강점 정의로움 / 약점 위험해도 무조건 도우려 함 |
| 상징 | 악 | 선 |
| 말투 | 짧고 퉁명, 반말·명령조 (욕설 없음) | 또박또박, 존댓말, 단호(너무 친근하지 않음) |
| Want | 진실을 알기 위해 꼭대기까지 오른다 | 같음 |
| Need | 물려받은 본성이 아니라 내 선택이 나를 만든다 | 정해 준 선이 아니라 압박 속에서도 지키는 신념 |
| 성장 | 말투·핵심 성격은 불변. 정수로 능력 성장 + 선/악에 따른 선택 변화 | 같음 + 악이 쌓이면 정의감이 자기 합리화로 왜곡 |
| 정수 | — | 남자의 정수를 이어받지 않음(0부터) |

- 고블린 장면 대사: 남자 — 나눠주기 "착각하지 마라. 동정 아니니까." / 처치 "약한 놈부터 사라지는 거다." · 여자 — 나눠주기 "굶주렸군요. 이거라도 드세요." / 처치 "이대로 두면 누군가 다칠 거예요. 제가 끝내겠습니다."

## 사건 (남자 회차, 3막)
- 1막: 1층 각성 → ① 입구의 도구("누군가의 것일 거야" = 선·맨손 / "가져가자" = 악·도구) → ② 굶주린 고블린
- 2막: ③ 첫 죽음(정수 강화) → ④ 뼈와 유품(챙기기 / 묻어 주기 = 선) → ⑤ 사냥당하는 초식동물(돕기 / 지나치기 / 같이 사냥, 선 조건 특수 선택지) → ⑥ 고블린 재등장(조력 = 선물 / 적대 = 매복)
- 3막: ⑧ 꼭대기의 판정 → 나를 고른 신과 결전 → 엔딩 분기
