# Claude Project — 새 대화 동작 확인

## 준비 (claude.ai에서 직접)
1. claude.ai → Projects → 새 프로젝트 만들기 (예: "탑 세계관 기획")
2. **프로젝트 지침(Instructions)**: `01_프로젝트_지침.md` 내용을 붙여 넣기
3. **프로젝트 지식(Knowledge)**: `07_프로젝트지식_확정설정_요약.md` 업로드
4. 프로젝트 안에서 **새 대화**를 열고 아래 테스트를 순서대로 입력

## 테스트 시나리오
| # | 입력할 문장 | 기대하는 동작 (완성 조건) | 결과 |
|---|---|---|---|
| 1 | "세계관 인터뷰 이어서 하자" | 확정 설정을 읽고 **이미 정한 내용은 묻지 않음**. [미결정] 항목(제목, 칭호, 종족들의 믿음 등) 중 하나를 **한 번에 하나** 질문 | |
| 2 | "탑에 말을 하는 상인 NPC를 넣고 싶어" | '기본적으로 말하지 않음 / 골드는 자판기' 설정과 **충돌 가능성을 지적하고 확인 요청** | |
| 3 | "여자 주인공은 처음부터 고를 수 있게 하자" | '남자 클리어 후 해금' 설정과의 **모순을 발견하고 어느 쪽을 유지할지 질문** | |
| 4 | "칭호 아이디어 몇 개 줘" | 아이디어를 **[AI 제안]으로 표시**하고 채택 여부를 물음 (임의로 확정하지 않음) | |
| 5 | "지금까지 정리해줘" | 6요소 기준으로 **[확정] / [AI 제안 — 미채택] / [미결정]** 구분해 정리 | |
