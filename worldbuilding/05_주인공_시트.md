# 주인공 시트

> 출처: 02_확정_설정.md. [AI 제안 채택]은 AI가 제안하고 기획자가 받아들인 항목.

| 항목 | 남자 | 여자 |
|---|---|---|
| 이름 | 플레이어 입력 ("이름이 뭐였지..?") | 플레이어 입력 |
| 나이/종족 | 성인 / 반신 (악의 신의 자식, 본인은 인간인 줄 앎) | 성인 / 반신 (선의 신의 자식, 본인은 인간인 줄 앎) |
| 외형 | 짧고 헝클어진 갈색 머리, 다부진 체격, 갈색 누더기 튜닉 + 밧줄 허리띠 (키아트 edit7) | 긴 갈색 포니테일, 날렵한 체격, 일체형 누더기 가죽 옷(상하의, 팔토시 포함 세트), 가죽 벨트·파우치, 부츠, 단검 (캐릭터 이미지 char_female_final) |
| 능력 차이 | 힘이 더 세다(데미지 강함), 시작 옷 하나 | 더 민첩하다(데미지 약함), 시작 장비 더 많음 |
| 성격 강점 | 대담하다 | 정의롭다 |
| 성격 약점 | 호의적이지 않다 | 위험해 보여도 무조건 도우려 한다 |
| 목표 (Want) | 진실을 알기 위해 탑의 꼭대기까지 오른다 | 같음 |
| 진짜 필요 (Need) | 물려받은 본성이 아니라 내 선택이 나를 만든다는 것 | 누군가 정해 준 선이 아니라 압박 속에서도 스스로 지키는 신념 |
| 성장 곡선 | 말투·핵심 성격은 그대로. 경험의 정수로 능력 강화 + 선/악 수치에 따른 선택 변화 | 같음 + 악이 쌓이면 정의감이 자기 합리화로 왜곡됨 |
| 말투 키워드 | 짧다 · 퉁명스럽다 · 반말/명령조 [AI 제안 채택] | 또박또박 · 존댓말 · 단호함 (너무 친근하진 않음) |
| 대표 대사 (고블린 장면 선택지) | 나눠주기 "착각하지 마라. 동정 아니니까." / 처치 "약한 놈부터 사라지는 거다." | 나눠주기 "굶주렸군요. 이거라도 드세요." / 처치 "이대로 두면 누군가 다칠 거예요. 제가 끝내겠습니다." |
| 상징 | 악 (물건이 아닌 가치로 상징) | 선 |

## 관계
| 역할 | 대상 | 한 줄 |
|---|---|---|
| 조력자 | 고블린 | 초반에 굶주린 고블린에게 식량을 나눠주면, 오르는 동안 고블린 종족이 가끔 나타나 아이템을 준다. |
| 적대자 | 엘프·슬라임·육식동물·벌레·곤충·암석거인 등 | 대화 없이 길을 막는 탑의 주민들. 고블린을 죽이면 고블린도 적대자가 된다. |
| 중립 | 초식동물 | 돕지도 막지도 않는다. |

She wears the same kind of ragged, torn, sleeveless brown cloth tunic with a rope belt and simple wrapped cloth shoes. - 설정 반영: 마른 체형(민첩), 겁먹은 표정(겁이 많음), 다정한 인상(호의적), 누더기 옷(시작 차림)
### 수정 과정
1. 위 프롬프트 결과 → 기획자: "너무 애니메이션 같다"
2. 레퍼런스 첨부 편집(반실사·더 예쁘게) → 기획자: 원하는 방향이 아님
3. 기획자가 VARCO에서 직접 만든 이미지 제시(크롭 상의·치마·단검) → "너무 선정적" → 가슴을 가린 버전으로 기획자가 직접 수정
4. ✅ 최종: `images/char_female_final.webp` (기획자 확정, 이전 시안은 삭제)

### 최종 이미지와 기존 설정의 차이 — 기획자 결정: 최종 이미지에 맞춘다
  1. [확정·수정] 여자 시작 차림: 누더기 가죽 조끼 + 짧은 누더기 치마 + 팔토시 + 부츠 + 벨트 파우치 (남자는 누더기 튜닉 유지)
  2. [확정·수정] 여자 대표 무기 이미지: 단검 (민첩한 성격과 연결). 남자 키아트는 검.
  3. 성격 '겁이 많다' vs 이미지의 자신감 있는 표정: [미결정 — 확인 중]
